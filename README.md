## About The Project

**Clean Commerce** is a regular e-commerce application with a special purpose — demonstrating how **Clean Architecture** combined with **MVVM** and **SOLID principles** creates maintainable, testable, and scalable Flutter apps.

### Features

| Feature | Description |
|---------|-------------|
| 🛒 **Products** | Browse, search, filter, and view product details |
| 📦 **Orders** | Create orders, view history, and track status |
| 🚚 **Order Tracking** | Real-time order status updates |
| 🔐 **Authentication** | Email/Password login & registration with Supabase Auth |
| 💳 **Payments** | Secure checkout flow (ready for gateway integration) |
| 🎨 **Theme** | Light/Dark mode with persistent user preference |

---

## Tech Stack

| Technology | Purpose |
|------------|---------|
| **Flutter** | UI Framework |
| **Supabase** | Backend (Auth, PostgreSQL, Realtime) |
| **Hive** | Local Storage (Offline cart, theme preference) |
| **Riverpod** | State Management |
| **GetIt** | Dependency Injection |
| **Sizer** | responsive design |
| **cached_network_image** | caching products images to show offline |
| **shared_preferences** | caching data and settings |
| **flutter_secure_storage** | auth token storage |
